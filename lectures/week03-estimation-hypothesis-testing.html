Estimation, Confidence Intervals & Hypothesis Testing

Turning a sample statistic into a defensible claim about the population it came from.

At a glance

Inference moves from a single sample to a claim about the population. This week covers point and interval estimation, the logic of hypothesis testing, the two ways a test can be wrong, and the t-test as a first worked example — the direct precursor to regression inference in Weeks 4 and 6.

EstimateA point estimate plus its uncertainty (standard error).
IntervalA confidence interval expresses a plausible range for the true parameter.
TestA hypothesis test asks whether the data are surprising under a null claim.
A

Point estimation

A point estimate is a single best guess for a population parameter, calculated from sample data (e.g., $\bar{x}$ estimates $\mu$). Two properties judge how good an estimator is.

BiasDoes the estimator's average value across repeated samples equal the true parameter?
PrecisionHow much does the estimator vary from sample to sample (its standard error)?
An ideal estimator is unbiased and precise. A biased-but-precise estimator is consistently wrong; an unbiased-but-imprecise one is right on average but unreliable in any single study.
B

Confidence intervals

A confidence interval (CI) pairs a point estimate with a margin of error built from the standard error.

$$\bar{x} \pm z^{*}\cdot SE(\bar{x})$$

For a 95% CI, $z^{*}\approx 1.96$. Correct interpretation: if we repeated the sampling process many times, about 95% of the intervals constructed this way would contain the true population parameter. It is not a 95% probability that this particular interval contains the truth.

What widens or narrows a CI

  • Larger sample size → smaller SE → narrower CI.
  • Higher confidence level (e.g., 99% vs. 95%) → larger $z^{*}$ → wider CI.
  • More variable data (larger $\sigma$) → wider CI.
C

Hypothesis testing framework

A hypothesis test asks: if the null hypothesis were true, how unusual would data like ours be?

  1. State $H_0$ (no effect/no difference) and $H_A$ (the effect exists).
  2. Choose a significance level $\alpha$ (typically 0.05).
  3. Compute a test statistic that measures how far the data are from $H_0$.
  4. Convert the test statistic to a p-value.
  5. Reject $H_0$ if $p < \alpha$; otherwise, fail to reject $H_0$.
A p-value is P(data this extreme or more extreme | $H_0$ is true) — it is not the probability that $H_0$ is true, and "fail to reject" is not the same as "proven true."
D

Type I/II error & power

Type I error (α)Rejecting $H_0$ when it is actually true — a false positive.
Type II error (β)Failing to reject $H_0$ when it is actually false — a false negative.
Power (1−β)The probability of correctly detecting a true effect.

What increases power

  • Larger sample size.
  • Larger true effect size.
  • Less variable data.
  • A less stringent $\alpha$ (trades more Type I error risk for more power).
E

One- and two-sample t-tests

The t-test compares a sample mean to a fixed value (one-sample) or two sample means to each other (two-sample), using the t-distribution to account for estimating $\sigma$ from the sample.

$$t = \frac{\bar{x}_1 - \bar{x}_2}{SE(\bar{x}_1 - \bar{x}_2)}$$

The t-distribution has heavier tails than the normal, especially at small degrees of freedom (roughly $n-1$ or $n_1+n_2-2$), which corrects for the extra uncertainty of estimating the standard deviation rather than knowing it. As $n$ grows, the t-distribution converges to the normal — the same t-statistic logic reappears when testing regression coefficients in Weeks 4 and 6.

Common pitfalls

PitfallWhy it happensFix
"95% probability the true value is in this interval"The frequentist CI is a property of the procedure, not of a single realized interval.State it as: 95% of intervals built this way would capture the true parameter.
Treating p ≥ 0.05 as "no effect"Failing to reject $H_0$ can reflect low power, not truth of $H_0$.Report the CI and consider power/sample size before concluding "no effect."
Multiple testing without adjustmentEach test carries its own Type I error risk; running many inflates the overall false-positive rate.Pre-specify comparisons or adjust (e.g., Bonferroni), as revisited in Week 5's ANOVA post-hoc tests.

Exam prep

Five things to memorize

  • A CI combines a point estimate with $z^{*}$ (or $t^{*}$) times the standard error.
  • A p-value is the probability of data this extreme given $H_0$ is true, not the probability $H_0$ is true.
  • Type I error (α) is a false positive; Type II error (β) is a false negative; power is $1-\beta$.
  • Power rises with larger n, larger effect size, less variability, and a looser α.
  • The t-distribution replaces the normal when $\sigma$ is estimated from the sample, especially at small n.

Formula sheet

$$CI = \bar{x} \pm z^{*}\cdot SE \qquad t = \frac{\bar{x}_1-\bar{x}_2}{SE(\bar{x}_1-\bar{x}_2)}$$

Likely exam question

A study finds p = 0.08 for a plausible, clinically meaningful effect. Is this good evidence of "no effect"? What would you want to know before concluding that?

Answer with: p ≥ 0.05 does not prove $H_0$; check the CI's width and the study's power — a small, underpowered study can easily miss a real effect.

Mnemonic

Type I = false alarm (reject a true $H_0$); Type II = missed detection (fail to reject a false $H_0$); Power = your ability to catch a real effect.
